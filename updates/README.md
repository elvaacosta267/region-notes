# updates/ 사용법

업데이트 루프를 실행할 때마다 그날 날짜로 파일을 하나씩 추가합니다: `YYYY-MM-DD.md`

## 템플릿

```md
# 2026-08-15 업데이트

## 변경 사항
- [id: URB-sanbon-02] 산본9-2구역 재건축 — 사업시행인가 취득 (URB-04)
  - 출처: https://example.go.kr/notice/12345
- [id: PHZ-hanam-01] 하남교산 — 실시계획 승인 고시 (PHZ-04)
  - 출처: https://example.go.kr/notice/67890

## 신규 추가
- (해당 회차에 새로 추적을 시작한 사업이 있으면 기재)

## 특이사항
- (여론, 지연 사유, 관련 소송 등 자유 기술)
```

## 원칙
- 하나의 업데이트 로그 = 하나의 대화 세션(한 번의 "최신 진행상황 반영해줘" 요청).
- `plans.csv`의 변경분과 반드시 1:1로 대응해야 함 (로그에 없는 csv 변경은 만들지 않는다).
- 출처 URL 없는 변경은 기록하지 않는다.
