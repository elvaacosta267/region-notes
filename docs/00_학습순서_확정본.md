# 수집·학습 순서 (확정본 — 2차 계획부터, 시간순)

> 1차 국토종합개발계획(1972~1981)은 복구·기반시설 조성기라 제외.
> **오래된 것부터 순서대로** 학습 — 시대별 우선순위 로직 변화와 이월사업을 자연스럽게 추적하기 위함.
> 문서 1건 학습 완료 = `docs/plans/<번호>_<계획명>.md` 생성 + 아래 체크.

| 2 | ☐ | 제1차 수도권정비계획 | 1982~1996 | 수도권정비계획법 최초 제정, 3개 권역 구분 시작 |

## 학습 끝나면 다음 단계 (Tier 3~5, 이전 마스터목록 참고)

위 10건(코어 학습) 끝나면, 광역교통기본계획·시도 도시기본계획·시군 정비기본계획으로 확장.
소재지 우선순위: 성남·고양·안양·부천·군포(1기 신도시) / 남양주·하남·인천계양·고양·부천·광명시흥·의왕군포안산·화성(3기 신도시).
