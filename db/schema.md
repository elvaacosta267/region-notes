## 단계코드 (사업유형별)

**신도시/택지 (공공주택특별법)**
`구상발표 → 지구지정 → 지구계획승인 → 토지보상 → 조성공사 → 사전청약 → 본청약 → 착공(주택) → 입주 → 완료`

**정비사업 (도시정비법)**
`기본계획 → 정비구역지정 → 추진위 → 조합설립 → 사업시행인가 → 관리처분인가 → 이주철거 → 착공 → 준공 → 완료`

**노후계획도시 (1기 신도시)**
`선도지구선정 → 특별정비계획입안 → 특별정비구역지정 → 사업시행자지정 → 사업시행인가 → 관리처분 → 이주 → 착공 → 준공`

**광역교통 (GTX 등)**
`계획반영 → 예타통과 → 기본계획 → 실시협약/실시계획 → 착공 → 부분개통 → 전구간개통`

## 우선순위 판단의 2단 구조 (미이행 사업 분류용)

사업이 계획에만 있고 실행이 안 될 때, 원인을 두 레벨로 구분한다.

1. **비전(정치) 레벨** — 그 시기 정권의 국토정책 어젠다에 사업이 부합했는가.
   흐름: 성장거점개발(1~2차) → 균형발전·분권(4차, 참여정부) → 5+2 광역경제권(이명박) → 지역행복생활권(박근혜) → 도시재생뉴딜(문재인) → 기회발전특구(윤석열)
2. **재정(실행) 레벨** — 예비타당성조사(예타) 통과 여부. 1999년 도입, 국비 500억+ 사업은 이걸 못 넘으면 착수 자체가 불가능.

`예타상태`가 "미실시"인데 계획에는 계속 등장하는 사업 = **비전 레벨에서만 반복 언급되고 재정 관문을 넘은 적이 없는 사업** → 진행가능성 낮음으로 분류.
`예타상태`가 "통과"인데 계획단계에 멈춘 사업 = **재정은 확보됐는데 다른 사유(지자체 갈등, 인허가 등)로 지연** → 진행가능성 있음, 원인 추가 조사 필요.

## 운영 규칙
1. 상태가 바뀌면 **행을 수정**하고, 변경 내용은 `updates/YYYY-MM-DD.md`에 한 줄 기록 → git 커밋. 커밋 이력이 곧 타임라인.
2. id는 절대 재사용/변경하지 않는다 (지도·로그가 id로 연결됨).
3. 새 사업 추가 시 id는 마지막 번호 +1.
4. lat/lng이 확정 안 된 사업은 빈칸 허용 (지도에는 미표시).
