# db/plans.csv 스키마 정의

`plans.csv`는 이 저장소의 **단일 소스(source of truth)** 입니다.
모든 파생물(geojson, kml, 지도)은 이 파일에서 생성됩니다.

## 컬럼 정의

| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `id` | string | 고유 식별자. 한 번 부여되면 **불변**. 형식: `<법률약자>-<지역>-<일련번호>` 예) `PHZ-namyangju-01`, `URB-sanbon-02` |
| `name` | string | 사업/계획명 (예: 남양주왕숙 공공주택지구, 산본9-2구역 재건축) |
| `category` | string | 대분류. 아래 "카테고리" 참고 |
| `law_basis` | string | 근거 법률. 아래 "법률 약자" 참고 |
| `region` | string | 시·군·구 (예: 경기 남양주시) |
| `stage_code` | string | 현재 진행단계 코드. 법률별 코드는 아래 "단계코드" 표 참고 |
| `stage_name` | string | 단계코드에 대응하는 한글 명칭 (사람이 읽기 위한 캐시, stage_code가 원본) |
| `stage_date` | date (YYYY-MM-DD) | 해당 단계 도달일. 모르면 YYYY-MM 또는 YYYY만 기재 |
| `lat` | float | 위도 (대표 좌표, 정비구역 등은 대략 중심점) |
| `lon` | float | 경도 |
| `source_url` | string | 이번 상태값의 근거가 된 고시/보도자료 URL. **필수** |
| `last_updated` | date | 이 행을 마지막으로 수정한 날짜 (Claude 업데이트 실행일) |
| `note` | string | 특이사항, 지연 사유, 반대 여론 등 자유 기술 |

## 카테고리 (category)

- `3기신도시` — 공공주택특별법 기반 대규모 택지
- `GTX` — 광역교통법 기반 광역철도
- `1기선도지구` — 노후계획도시특별법 기반 1기 신도시 정비
- `정비사업` — 도시정비법 기반 재건축/재개발/리모델링
- `광역계획` — 국토계획법 기반 도종합/수도권정비계획 등 상위계획

## 법률 약자 (law_basis)

| 약자 | 법률명 |
|---|---|
| `NLP` | 국토의 계획 및 이용에 관한 법률 (국토계획법) |
| `URB` | 도시 및 주거환경정비법 (도시정비법) |
| `PHZ` | 공공주택 특별법 |
| `OLD` | 노후계획도시 정비 및 지원에 관한 특별법 |
| `TRN` | 대도시권 광역교통 관리에 관한 특별법 (광역교통법) |

## 단계코드 (stage_code) — 법률별 표준 절차

### PHZ (공공주택특별법) — 3기 신도시 등
1. `PHZ-01` 지구지정 예고(주민공람)
2. `PHZ-02` 지구지정 고시
3. `PHZ-03` 지구계획 승인
4. `PHZ-04` 실시계획 승인
5. `PHZ-05` 착공
6. `PHZ-06` 준공/입주

### URB (도시정비법) — 재건축·재개발
1. `URB-01` 정비계획 수립/정비구역 지정
2. `URB-02` 추진위원회 승인
3. `URB-03` 조합설립인가
4. `URB-04` 사업시행인가
5. `URB-05` 관리처분계획인가
6. `URB-06` 이주·철거
7. `URB-07` 착공
8. `URB-08` 준공/입주

### OLD (노후계획도시특별법) — 1기 신도시 등
1. `OLD-01` 기본계획 수립
2. `OLD-02` 선도지구 지정
3. `OLD-03` 특별정비계획 수립
4. `OLD-04` 특별정비구역 지정
5. `OLD-05` 사업시행계획 인가
6. `OLD-06` 착공
7. `OLD-07` 준공/입주

### TRN (광역교통법) — GTX 등
1. `TRN-01` 노선 확정(기본계획 반영)
2. `TRN-02` 사전타당성/예비타당성 통과
3. `TRN-03` 기본계획 고시
4. `TRN-04` 실시계획 승인
5. `TRN-05` 착공
6. `TRN-06` 개통

### NLP (국토계획법) — 상위 광역계획
1. `NLP-01` 계획 수립 착수
2. `NLP-02` 공청회/주민의견 청취
3. `NLP-03` 승인·고시
4. `NLP-04` 재정비/변경 고시
5. `NLP-05` 계획기간 만료(차기 계획으로 이관)

> 새로운 법률이나 절차가 추가되면 이 표에 먼저 정의한 뒤 plans.csv에 반영합니다.
